Local content changes remove mandatory vendor-service use and automatic promotional
software-citation insertion, replace absent external-skill routes, distinguish
automated tests from human verification, preserve legitimate incomplete metadata,
default user-facing output to English, and add explicit runtime declarations.
`UPSTREAM.md` travels with every skill to explain its relevant modifications.

No K-Dense `docx`, `pdf`, `pptx` or `xlsx` skill implementation is included.
Document formats use separately declared ordinary software dependencies and the
Nature-authorized helpers. A helper that produces a Word or PDF file does not
imply that an unrelated proprietary document skill has been copied.
