# Calibrating proposal commitments (De-commit Pattern)

English translation by OC Science Lab, 2026-09-09. Original licensing and attribution apply. The source filename is preserved for manifest compatibility.

When writing within an approved proposal, a common mistake is to turn an exploratory direction into a core deliverable. Reducing commitment means aligning its strength with evidence, rather than simply deleting content.

## Triggers

- The project is approved and this proposal develops its framework.
- Fundamental theoretical, chemical, engineering or ethical constraints prevent the original route from supporting strong commitments.
- The supervisor explicitly asks not to introduce an unrelated novel direction.

## Three commitment levels

| Level | Definition | Wording |
|---|---|---|
| **Deliverable workstream** | Strong literature support and available experimental conditions: must deliver | “Establish …”; “determine …” |
| **Cautious exploration** | Literature provides leads, but transferring to this system is risky: investigate without guaranteeing success | “Explore the feasibility of …”; “test whether … holds” |
| **Boundary assessment** | Answer whether something is feasible, without promising optimization | “Determine the operating window and Go/No-Go criteria for …” |

## Procedure

1. **List all claims** and assign each a commitment level.
2. **Narrow the central workstream:** retain only deliverable workstreams as core outputs.
3. **Downgrade exploratory work:** move a former “core innovation” to cautious exploration, with failure criteria and a fallback.
4. **State boundaries explicitly:** “If X is infeasible, return to route Y.”
5. **Rewrite positioning sentences:** framing throughout the document must reflect the recalibrated commitments.

## General example: a high-risk intervention route

**Before:** Method X is the central route and will actively control the target variable to establish a stable process.

**After:** Method X supports state identification and feasibility-boundary assessment; active control and process optimization begin only after the Go/No-Go criteria are met.

**Reasoning:**

- Existing literature shows only that method X can measure the relevant state.
- In the target system, intervention may also change critical boundary conditions.
- Current evidence cannot distinguish the intended effect from system disturbance.
- Therefore, initially use X for monitoring and boundary validation, retaining the well-supported baseline as the main route.

## Complete workflow with professor review

```text
Initial proposal → professor Convener (2–3 experts)
    → revision brief (P0/P1/P2 priorities)
    → user discussion and direction confirmation
    → editing instructions → external editor (GPT/Codex)
    → user revisions
    → final draft
```

Not every proposal requires this entire chain. Begin the commitment-reduction process only when professor review identifies a P0 commitment problem.
